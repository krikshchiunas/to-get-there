# Модерация

Как в To Get There разбираются жалобы. Это порядок для команды проекта, а
для пользователей — короткая версия в [правилах сообщества](../app/legal/community/page.tsx).

## Откуда приходят жалобы

У каждого сообщения, идеи, профиля и личного сообщения есть «⋯ → Пожаловаться».
Жалоба — строка в `public.reports` (миграция 0030):

| Поле | Что это |
|---|---|
| `target_type`, `target_id` | на что пожаловались: `user`, `post`, `message`, `direct_message` |
| `target_user_id` | чей это контент — по нему видно повторных нарушителей |
| `reason`, `details` | причина из списка и пояснение (до 1000 символов) |
| `snapshot` | копия содержимого **на момент жалобы**: удалить нарушение до проверки не выйдет |
| `status` | `open` → `actioned` или `dismissed` |

Пользователь видит только свои жалобы. Тот, на кого жалуются, не видит ничего.
На одну цель — одна жалоба от человека; больше 30 в сутки от одного человека
база не примет (0031).

## Очередь

Supabase → SQL Editor:

```sql
select * from private.moderation_queue where status = 'open';
```

Открытые жалобы идут первыми, цели с несколькими жалобами — выше.
`actioned_against_user` — сколько раз против этого человека уже принимали меры.

## Сроки (DSA, ст. 16)

| Что | Срок |
|---|---|
| угрозы жизни, насилие, сексуальное насилие над детьми | сразу; при угрозе жизни — полиция (110) |
| травля, ненависть, домогательства, мошенничество | в течение 24 часов |
| спам, выдача себя за другого, прочее | в течение 72 часов |

## Решения

1. **Удалить содержимое.** Сообщение, идею или личное сообщение — через Table
   Editor или SQL от `service_role`. Каскады уберут ответы и голоса; фото в
   Storage удалить отдельно (бакет `post-media`, папка идеи).
2. **Предупредить.** Письмо на почту аккаунта (`auth.users.email`).
3. **Ограничить.** Удалить человека из чатов идей (`post_participants`).
4. **Закрыть аккаунт.** Supabase → Authentication → Users → Delete user. Каскад
   удалит профиль и всё, что он написал.

После решения:

```sql
update public.reports
set status = 'actioned', resolved_at = now()   -- или 'dismissed'
where target_type = '…' and target_id = '…';
```

## Объяснение и обжалование (DSA, ст. 17 и 20)

Тому, чьё содержимое удалили или чей аккаунт ограничили, — письмо: что удалено,
какое правило нарушено, как обжаловать (ответить на письмо). Обжалование
рассматривает **другой** модератор, не тот, кто принимал решение.

Тому, кто пожаловался, — короткий ответ, что жалоба рассмотрена.

## Сроки хранения

Разобранные жалобы удаляются через 180 дней после решения (ночной cron,
`private.purge_expired()`, 0034). Открытые не удаляются никогда. Если
содержимое понадобилось полиции или суду — выгрузить снимок до удаления.

## Злоупотребление жалобами

Кто массово жалуется без оснований — видно по `reporter_nickname` в очереди.
Такие жалобы отклоняются (`dismissed`), а при систематическом злоупотреблении
действуют те же шаги, что для любого нарушения.
