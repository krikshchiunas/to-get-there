# Дизайн

Документ фиксирует решения и причины, чтобы следующий заход спорил с ними,
а не угадывал.

## Что было и почему не сработало

Первая версия строилась вокруг метафоры табло отправления: у каждой идеи есть
время, место и количество мест, значит лента — это расписание. Слева шёл рельс
шириной 68px с временем крупным узким гротеском, по рельсу через всю группу дня
проходила линия маршрута, каждая идея лежала в карточке с рамкой.

Метафора верная, исполнение — нет. Пользователь сказал «тяжело», и он прав:

- рамка вокруг каждой идеи, внутри неё плашки, разделитель и залитая кнопка —
  контейнер внутри контейнера;
- 18% ширины телефона навсегда отданы под метку времени;
- четыре полужирных элемента на одной карточке борются за внимание;
- три строки метаданных вместо одной;
- две гарнитуры, одна из них узкая и плотная.

Это язык дашборда. Лента соцсети устроена иначе.

## Что показали замеры

Вместо того чтобы вспоминать, как выглядят Instagram и Twitter, мы открыли
живые ленты и сняли вычисленные стили (октябрь 2026). Instagram и X закрыты
логином, поэтому замерялись **Threads** — дизайн-язык Meta, тот же, что в
Instagram, — и **Bluesky**, прямой наследник Twitter.

| | Threads | Bluesky |
| --- | --- | --- |
| Фон | `#ffffff` | `#ffffff` |
| Текст поста | 15px / 21px, вес 400 | 16px, вес 400 |
| Метаданные | 15px, `#999` | 15px, `#405168` |
| Ролей цвета текста | 2 | 2 |
| Разделение постов | линия 0.5px во всю ширину | линия 1px во всю ширину |
| Карточка вокруг поста | нет | нет |
| Теней на элементах >300px | нет | ровно 0 |
| Аватар | ~40px | 42px |
| Кнопка | пилюля, вес 400 | пилюля, h33, вес 400 |
| Вторичная кнопка | заливка без рамки | заливка `#eff2f6` без рамки |

Вывод, который не читается из скриншотов, но виден в цифрах: **тяжесть даёт не
цвет, а контейнеры и вес**. Обе ленты — плоский список на одном фоне, где
почти весь текст одного размера и одного веса, а иерархия держится на цвете и
положении.

## Правила, которые из этого следуют

1. **Нет карточек.** Элемент списка лежит на фоне, отделён снизу линией во всю
   ширину колонки.
2. **Нет теней.** Ни одной.
3. **Вес 400 почти везде.** 500 — только ник автора, название идеи, время,
   активная вкладка.
4. **Две роли цвета текста:** содержание и служебное.
5. **Рамку заменяет заливка** — кнопки, поля, чипы.
6. **Цвета почти нет.**
7. **Одна гарнитура.**

## Чего мы сознательно не копируем

В Twitter таймстамп — это мелочь, «2 ч назад». Здесь время — главное решение
пользователя: успею или нет. Поэтому время остаётся единственным исключением
из правила «всё служебное серое»: оно стоит справа в первой строке, набрано
основным цветом с табличными цифрами и краснеет, когда до начала меньше трёх
часов. Группировка по дням тоже остаётся — у лент её нет, но у расписания она
есть, и это конвенция мессенджеров, а не дашбордов.

Разделитель `·` в строке метаданных контракт раньше запрещал как типовой
признак сгенерированного интерфейса. Запрет снят: все три изученные ленты
используют именно его, и читается он мгновенно. Правило существовало против
безликости, а не против работающей конвенции.

## Строка ленты

```
Сегодня                                       ← заголовок группы
┌ px-4 py-3.5, снизу линия во всю ширину ─────────────────┐
│ [40px]  jonas_k ✓  TU Berlin           19:30            │
│         Пиво у канала после занятий                     │
│         После последней лекции идём на Ландверканал…    │
│         Kreuzberg · 3 места свободно      💬 5           │
└─────────────────────────────────────────────────────────┘
```

Аватар — якорь слева: в ленте соцсети колонку держит человек, а не метаданные.
Залитой кнопки на строке нет — вся строка открывает идею, как в любой ленте,
а иконка чата со счётчиком играет роль действия.

## Цвет

| Токен | Светлая | Роль |
| --- | --- | --- |
| `paper` / `surface` | `#ffffff` | один фон, без второго уровня |
| `sunken` | `#f2f3f6` | заливка вместо рамки |
| `ink` / `ink-soft` | `#101418` / `#5b6472` | содержание и служебное |
| `ink-faint` | `#949cab` | только заголовки групп |
| `line` | `#e6e8ec` | разделители |
| `signal` | `#2f3bee` | действие, и только оно |
| `heat` | `#e02a52` | **только** близость события и удаление |
| `verified` | `#1a7f64` | **только** подтверждённая личность |

Тёмная тема — те же роли от `#0b0d12`.

## Шрифт

**Golos Text**, одна гарнитура на всё. Кириллическая по происхождению, поэтому
русский набирается, а не подставляется системным шрифтом. Первая пара —
Archivo и Instrument Sans — отпала сразу: в них нет ни одного кириллического
глифа. Вторая — Oswald для расписания плюс Golos Text для текста — отпала
вместе с рельсом: все изученные ленты держат ровно одно семейство, и это одна
из причин, почему они выглядят легко.

## Движение

`u-rise` на том, что открывается. Больше ничего. `prefers-reduced-motion`
учитывается глобально.
